# Memoria/Journal/

Reflexiones de sesión del agente: qué funcionó, qué no, qué patrón vio en el usuario, qué correcciones recibió.

Diferente del `Journal/` del vault (diario del usuario). Aquí el agente anota su propia bitácora.

Formato libre. Nomenclatura sugerida: `YYYY-MM-DD-session-N.md` o `YYYY-MM-DD-short-slug.md`.

Ver `../README.md` para reglas generales de Memoria/.
